# 📊 Data Analytics Project 4 — Data Visualization

## DecodeLabs Data Analytics Industrial Training | Batch 2026

This project is the **Data Visualization** stage of my DecodeLabs Data Analytics journey. It reuses the same e-commerce dataset developed through the earlier projects so the portfolio demonstrates a continuous analytics workflow:

**Project 1 → Data Cleaning & Preparation → Project 2 → EDA → Project 3 → SQL Analysis → Project 4 → Data Visualization**

## 🎯 Project Goal

Create clear visual representations of data that communicate analytical insights to a business audience.

The training material emphasizes that visualization is not simply about making attractive charts. The goal is to translate complex numbers into clear visual evidence and a business narrative.

## 📂 Dataset

Source: the cleaned dataset carried forward from the previous projects.

- Records: **1,200**
- Date range: **2023-01-01 to 2025-06-30**
- Products: Chair, Printer, Laptop, Tablet, Monitor, Desk, Phone
- Total sales: **₹1,264,761.96**
- Average order value: **₹1,053.97**

## 📈 Visualizations Created

1. **Product Sales** — category comparison
2. **Monthly Sales Trend** — time-series analysis
3. **Order Status** — order-volume comparison
4. **Referral Source Sales** — marketing-source comparison
5. **Payment Method Sales** — payment-value comparison

## 💡 Key Observations

- Chair and Printer have almost identical total sales and lead the product comparison.
- Monthly sales fluctuate across the available period.
- Cancelled orders are the largest status group by order count.
- Instagram has the highest total sales among referral sources.
- Credit Card and Online are the two highest-sales payment methods.

## 🧠 Visualization Principles Applied

- **Form follows function:** the chart type follows the analytical question.
- **Bar charts:** used for comparing categories.
- **Line chart:** used for a continuous time trend.
- **Axis integrity:** avoid misleading visual distortion.
- **High data-ink ratio:** keep attention on the data.
- **Action-oriented titles:** titles communicate the main observation.
- **Direct explanation:** each chart includes the question it is intended to answer.
- **5-second rule:** the dashboard begins with KPIs and a concise executive story.
- **So What?:** observations are translated into clear analytical takeaways.
